## Selected Projects

**StudyMate** (Final Year Project) — *React, Django, LangChain, Groq LLM, FAISS, Redis, Celery, Docker*
- Hybrid RAG pipeline: FAISS + BM25 retrieval with query rewriting, semantic re-ranking, and grounded LLM generation
- Real-time WebSocket collaboration: study sessions, chat, file sharing, presence indicators via Django Channels + Redis
- Adaptive assessments: auto-generated quizzes, flashcards, mindmaps, AI-curated summaries
- Voice interface: Deepgram STT + ElevenLabs TTS integration
- Production deployment: Dockerised microservices, Vercel (frontend), Railway with ASGI/Daphne

**Detecting Anti-Jewish Hate Crimes** — *Python, Scikit-learn, SHAP, Random Forest*
- Random Forest achieved F1: 0.946, AUC: 0.978
- SHAP analysis for interpretability and bias detection
- Minority-class recall improved to 96.7% via engineered temporal and geospatial features

**Redmine QE Testing Framework** — *Selenium, JMeter, OWASP ZAP, SonarQube, Docker*
- End-to-end QA: manual testing, UI automation, API testing, performance, security
- Regression suites for issue creation, role permissions, workflow transitions
- Vulnerability assessment (OWASP ZAP) + static analysis (SonarQube)

**EventHub** — *ASP.NET Core, EF Core, SQL Server, Bootstrap*
- Full CRUD platform with user authentication and role-based access (admin/user)

**Motivation Diary** — *Java Servlets, JSP, HTML/CSS*
